Chegou a hora de transformar tudo o que você construiu ao longo do curso em uma vitrine profissional. Um portfólio bem-organizado é, muitas vezes, o primeiro contato de um recrutador com o seu trabalho — e no mercado de front-end, ele funciona como prova prática das suas habilidades, mais do que qualquer currículo. Neste exercício você vai desenvolver, com React, um portfólio online reunindo seus melhores projetos, suas habilidades e suas informações de contato, aplicando tudo o que aprendeu sobre componentização, estilização modular e deploy.

O que você vai desenvolver com esse exercício
Construção de uma aplicação React com múltiplas seções navegáveis
Aplicação de estilização modular (CSS Modules, Styled Components ou similar)
Curadoria e apresentação de projetos do curso como prova de competência técnica
Deploy de uma aplicação em produção (Vercel, Netlify, GitHub Pages, etc.)
O contexto do desafio
Você vai construir um portfólio dividido em quatro seções: "Sobre Mim" (apresentação, foto e contato), "Projetos" (pelo menos 3 projetos do curso, cada um com descrição, tecnologias usadas e link para repositório ou demonstração), "Habilidades" (tecnologias e competências adquiridas) e "Contato" (formulário ou links para redes sociais profissionais). O portfólio precisa ter uma página inicial com resumo profissional, navegação clara entre as seções, detalhamento de cada projeto com imagens e ser responsivo.

O que deve ser entregue
Repositório no GitHub com o código-fonte do portfólio
README.md explicando como rodar o projeto localmente, como acessar a versão online e uma breve descrição dos projetos apresentados
Portfólio publicado (deploy), com o link incluído no README
Passo a passo
Planeje as quatro seções do portfólio: Sobre Mim, Projetos, Habilidades e Contato.
Crie o projeto em React e defina a estrutura de componentes reutilizáveis para cada seção.
Implemente a seção "Sobre Mim", com apresentação, foto e informações de contato.
Implemente a seção "Projetos", com pelo menos 3 projetos do curso, cada um com descrição, tecnologias usadas, imagens/capturas de tela e link para repositório ou demonstração.
Implemente a seção "Habilidades", destacando as principais tecnologias e competências adquiridas.
Implemente a seção "Contato", com formulário ou links para redes sociais profissionais.
Implemente a navegação entre as seções e ajuste a responsividade para mobile e desktop.
Aplique estilização modular (CSS Modules, Styled Components ou equivalente).
Revise e comente o código, seguindo boas práticas de React e JavaScript.
Faça o deploy do portfólio em uma plataforma gratuita (Vercel, Netlify, GitHub Pages, etc.).
Escreva o README.md com instruções de execução local, link de acesso online e descrição dos projetos.
Suba o repositório no GitHub e compartilhe o link conforme as instruções da plataforma.
Requisitos obrigatórios
A avaliação considera a organização clara de arquivos, componentes e pastas por responsabilidade, a facilidade de navegação entre as seções (intuitiva e responsiva), a qualidade e variedade dos projetos apresentados (mínimo de 3, bem descritos, demonstrando tecnologias diferentes), o funcionamento correto das funcionalidades (navegação, exibição de informações, links e formulário de contato), a disponibilidade do portfólio online com documentação clara, e o uso adequado de componentes, hooks e props em React, sem repetições desnecessárias. Não é obrigatório usar um framework de estilização específico — qualquer método de estilização modular é aceito.

Formato da entrega
Link de repositório público no GitHub
Link do portfólio publicado (incluído no README.md)
